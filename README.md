## 🧾 Overview

www.shuhao-fosure.com

**shuhao-fosure** is a full-stack web application built independently to showcase end-to-end web development capabilities. It features secure authentication, data visualization, and Excel export functionalities. This project demonstrates my full-stack engineering skills in both backend API design and frontend UI construction.

## 🔧 Tech Stack
- **Frontend**: React, React Router, Create React App (CRA)
- **Backend**: Node.js, Express
- **Database**: MongoDB (Mongoose)
- **Authentication**: JWT (JSON Web Token)
- **Libraries Used**: Chart.js, XLSX
- **Dev Tools**: Postman, Git, VSCode, concurrently, nodemon

## 💡 Key Features
- 🔐 User login & registration with JWT-based auth
- 📊 Dynamic charts using Chart.js
- 📁 Export data to Excel with `xlsx`
- ⚙️ RESTful API integration with protected routes
- 🎨 Responsive and modular React UI

## 🚀 Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com/yourusername/shuhao-fosure.git
cd shuhao-fosure
2. Install and Start the Backend
cd server
npm install
npm run server
3. Install and Start the Frontend
cd ../client
npm install
npm start
Frontend runs at http://localhost:3000
Backend runs at http://localhost:5400
